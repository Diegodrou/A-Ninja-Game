# Little Ninja

**Little Ninja** is a 2D platformer game built with **Pygame**.
I created this project as a fun way to learn **Python** programming while exploring basic game development concepts like physics, animation, and level design.

---

## How to Play

| Action                              | Key           |
| ----------------------------------- | ------------- |
| Move Left                           | ← Left Arrow  |
| Move Right                          | → Right Arrow |
| Jump                                | ↑ Up Arrow    |
| Attack                              | F             |
| Restart / Load Next Level (in menu) | Space         |

---

## Installation

1. Make sure you have **Python 3** and **Pygame** installed:

   ```bash
   pip install pygame
   ```

2. Clone the repository:

   ```bash
   git clone https://github.com/Diegodrou/A-Ninja-Game.git
   cd A-Ninja-Game
   ```

3. Run the game:

   ```bash
   python Main.py
   ```
